# Landing Page (Web Dev – Level 1, Task 1)
Responsive landing page for a fictional coffee subscription, built with HTML5 and CSS3 only (no JavaScript).

**Features:** sticky navbar with 4 links and a CSS-only mobile menu, hero with headline, subheadline and two CTA buttons, Features, How it works, Pricing and Reviews sections, email sign-up form with built-in validation, multi-column footer, CSS Grid/Flexbox layout, CSS variables for the palette, keyboard focus styles, skip link, reduced-motion support.

**Run:** open `index.html` in a browser (or use VS Code Live Server).
**Screenshots:** add to a `screenshots/` folder.
